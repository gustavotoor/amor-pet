# Configuração do Ambiente - Amor Pet

## Estrutura do Projeto
- **frontend**: Interface do usuário desenvolvida com React
- **backend**: API RESTful desenvolvida com Node.js/Express
- **docs**: Documentação do projeto
- **wireframes**: Wireframes e protótipos

## Tecnologias Utilizadas

### Frontend
- React
- React Router DOM
- Bootstrap/React Bootstrap
- Axios
- React DatePicker
- Styled Components
- React Icons

### Backend
- Node.js
- Express
- PostgreSQL
- Sequelize (ORM)
- JWT (Autenticação)
- Bcrypt (Criptografia)
- Nodemailer (Envio de e-mails)
- Multer (Upload de arquivos)

### Banco de Dados
- PostgreSQL
