# Wireframe de Baixa Fidelidade - Cadastro e Login Amor Pet

## Tela de Login
- Logo "Amor Pet" (centralizado no topo)
- Título: "Entrar na sua conta"
- Formulário de login:
  - Campo de e-mail
  - Campo de senha
  - Checkbox "Lembrar-me"
  - Botão "Esqueci minha senha"
  - Botão primário "Entrar" (verde-água #A8D5BA)
- Separador com texto "ou"
- Botão "Entrar com Google" (com ícone do Google)
- Texto de rodapé: "Ainda não tem conta? Cadastre-se"
- Link para cadastro

## Tela de Cadastro
- Logo "Amor Pet" (centralizado no topo)
- Título: "Criar sua conta"
- Formulário de cadastro:
  - Campo de nome completo
  - Campo de e-mail
  - Campo de telefone
  - Campo de senha
  - Campo de confirmação de senha
  - Checkbox "Aceito os termos de uso e política de privacidade"
  - Botão primário "Cadastrar" (verde-água #A8D5BA)
- Separador com texto "ou"
- Botão "Cadastrar com Google" (com ícone do Google)
- Texto de rodapé: "Já tem uma conta? Entrar"
- Link para login

## Tela de Recuperação de Senha
- Logo "Amor Pet" (centralizado no topo)
- Título: "Recuperar senha"
- Texto explicativo: "Informe seu e-mail cadastrado para receber um link de recuperação de senha"
- Campo de e-mail
- Botão primário "Enviar link" (verde-água #A8D5BA)
- Link para voltar ao login

## Tela de Confirmação de E-mail
- Logo "Amor Pet" (centralizado no topo)
- Ícone de confirmação (marca de verificação)
- Título: "Verifique seu e-mail"
- Texto: "Enviamos um link de confirmação para seu e-mail. Por favor, verifique sua caixa de entrada e clique no link para ativar sua conta."
- Botão secundário "Reenviar e-mail" (azul claro #B3D4E5)
- Botão primário "Voltar para login" (verde-água #A8D5BA)

## Tela de Redefinição de Senha
- Logo "Amor Pet" (centralizado no topo)
- Título: "Criar nova senha"
- Campo de nova senha
- Campo de confirmação de nova senha
- Botão primário "Salvar nova senha" (verde-água #A8D5BA)

## Paleta de Cores
- Verde-água (#A8D5BA): Botões primários, destaques
- Azul claro (#B3D4E5): Botões secundários, elementos de fundo
- Bege (#F5E8C7): Fundo de formulários, áreas neutras
- Laranja suave (#F4A261): Alertas, notificações
- Branco: Fundo principal
- Cinza escuro: Textos principais

## Responsividade
- Em dispositivos móveis:
  - Formulários ocupam toda a largura da tela
  - Espaçamento reduzido entre elementos
  - Botões adaptados para toque (maior área clicável)
  - Fontes ajustadas para melhor leitura
